# TCSystem API Documentation

TCSystem is a collection of reusable .NET libraries for logging, image metadata, GPS data, SQLite metadata storage, threading, and general utilities.

## Libraries

- [TCSystem.Gps](xref:TCSystem.Gps) — Google Takeout location-history reading and lookup.
- [TCSystem.Logging](xref:TCSystem.Logging) — Serilog-based logging facade.
- [TCSystem.MetaData](xref:TCSystem.MetaData) — Immutable image metadata models and JSON serialization.
- [TCSystem.MetaDataDB](xref:TCSystem.MetaDataDB) — SQLite persistence for image metadata.
- [TCSystem.Thread](xref:TCSystem.Thread) — Worker-thread, semaphore, and asynchronous update helpers.
- [TCSystem.Util](xref:TCSystem.Util) — General extension methods and utility helpers.

Use the **API Reference** navigation to browse namespaces, types, public properties, and methods.
